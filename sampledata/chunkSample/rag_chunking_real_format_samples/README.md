# 真实格式业务文档分块样例集

本样例集面向企业知识库、档案知识库、制度知识库、项目资料库等生产环境。

## 文件类型

本版以真实生产环境更常见的文件为主：

- DOCX：制度、合同、会议纪要、操作手册、档案材料汇编
- XLSX：采购台账、档案移交清单、OCR质量日报
- PDF：扫描件/OCR、双栏版式、图表图注

不再使用 `.jsonl`、`.yaml`、`.sql`、`.properties` 作为主样例。

## 测试重点

1. DOCX 标题层级、条款、表格、会议议题、档案层级。
2. XLSX 工作表、表头、行记录、树形台账、字段含义。
3. PDF 页眉页脚、OCR 置信度、双栏阅读顺序、图表图注。
4. 检索时的小块召回、父块回填、同组补齐、权限和版本元数据保留。
