# 真实格式业务文档分块样例数据集（500份）

本数据集用于企业知识库、档案知识库、制度知识库、项目资料库的分块与检索回归测试。

## 文件数量

- DOCX：300 份
- XLSX：120 份
- PDF：80 份
- 合计：500 份

## 文件类型说明

本数据集以生产系统更常见的真实业务文档格式为主：

- DOCX：制度流程、合同采购、会议纪要、操作手册、验收报告、档案材料汇编
- XLSX：采购台账、资产台账、档案移交清单、问题跟踪表、OCR质量日报
- PDF：扫描件/OCR、签章合同、双栏报告、通知/图注材料

不使用 `.jsonl`、`.yaml`、`.sql`、`.properties` 作为主样例。

## 分块测试重点

1. DOCX 标题路径、条款、条件列表、付款节点表、会议议题、档案卷件层级。
2. XLSX 工作表、表头、行记录、树形台账、字段含义、金额/日期/状态列。
3. PDF 页眉页脚噪声、OCR 置信度、签章合同表格、双栏阅读顺序、图注引用。
4. 检索时的子块召回、父块回填、同组补齐、相邻块扩展和 metadata 继承。

## 元数据文件

- `metadata/dataset_manifest.csv`：500 份文件清单、类型、业务类别、分块问题、期望能力
- `metadata/chunking_test_questions.csv`：可用于检索回归的测试问题集

## 使用建议

1. 导入整个压缩包或按类型分批导入知识库。
2. 对比固定长度分块、递归分块、结构感知分块的差异。
3. 使用 `chunking_test_questions.csv` 做 Top-K 召回与 Expanded Evidence Recall 测试。
4. 对 DOCX/PDF/XLSX 分别观察解析结构是否保留。
