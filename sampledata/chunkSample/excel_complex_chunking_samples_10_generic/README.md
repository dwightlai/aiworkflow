# Excel复杂表格分块样例集（10份，示例人名版）

本数据集用于验证企业知识库对复杂 Excel 的结构识别和分块能力。

## 人名说明

所有人员姓名均使用张三、李四、王五、赵六、钱七、孙八、周九等示例人名，不包含真实人员姓名。

## 覆盖结构

1. 标准明细表：一行一条记录
2. 多行、合并表头
3. 合并单元格和分组数据
4. 一条记录包含大量长文本
5. 多工作表及跨表关联
6. 汇总表、统计报表、公式和图表
7. 树形台账、主从表
8. 表单式 Excel：字段和值分散布局
9. 公式、辅助列、批注说明类信息
10. 一个工作表包含多个独立表格

## 配套文件

- `metadata/dataset_manifest.csv`：样例文件说明和推荐分段策略
- `metadata/chunking_test_questions.csv`：导入知识库后的测试问题与期望答案
- `metadata/verification.csv`：基础验证结果
