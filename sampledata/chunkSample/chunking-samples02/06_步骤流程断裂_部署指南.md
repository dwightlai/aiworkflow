# AgentFlowy 生产环境部署指南

## 环境要求

- Linux Ubuntu 22.04 LTS / CentOS 8.0+
- Docker 24.0+ & Docker Compose v2.20+
- PostgreSQL 15+（推荐16）
- Redis 7.0+
- 内存 8GB+，磁盘 50GB+ SSD

---

## 部署步骤

### 第一步：环境准备

```bash
# 更新系统并安装基础依赖
apt update && apt upgrade -y
apt install -y curl wget git vim

# 安装 Docker
curl -fsSL https://get.docker.com | bash
systemctl enable docker && systemctl start docker

# 安装 Docker Compose
curl -L "https://github.com/docker/compose/releases/download/v2.24.0/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose
```

### 第二步：拉取部署配置

```bash
git clone https://github.com/agentflowy/deploy.git /opt/agentflowy
cd /opt/agentflowy
cp .env.example .env

# 编辑环境变量（必须修改以下项）
vim .env
```

### 第三步：配置数据库

在 `.env` 文件中填写数据库连接信息：

```env
DB_HOST=postgres
DB_PORT=5432
DB_NAME=agentflowy
DB_USER=agentflowy_user
DB_PASSWORD=请使用强密码，不少于32位随机字符串
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_PASSWORD=请使用强密码
JWT_SECRET=请使用随机生成的JWT密钥
```

### 第四步：初始化数据库

```bash
docker-compose up -d postgres redis
# 等待数据库启动（约15秒）
sleep 15
docker-compose run --rm api python manage.py migrate
docker-compose run --rm api python manage.py create_admin
```

### 第五步：启动服务

```bash
docker-compose up -d
# 查看服务状态
docker-compose ps
# 查看日志
docker-compose logs -f api
```

### 第六步：配置 Nginx 反向代理

```nginx
server {
    listen 443 ssl http2;
    server_name agentflowy.yourcompany.com;

    ssl_certificate     /etc/nginx/ssl/agentflowy.pem;
    ssl_certificate_key /etc/nginx/ssl/agentflowy.key;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### 第七步：验证部署

```bash
# 健康检查
curl https://agentflowy.yourcompany.com/api/health

# 预期返回：{"status": "ok", "version": "2.1.0", "db": "connected", "redis": "connected"}
```

## 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 502 Bad Gateway | API 服务未启动 | `docker-compose up -d api` |
| 数据库连接失败 | PostgreSQL 未就绪 | 等待15秒后重试，或增大 `docker-compose.yml` 中 `healthcheck` 的 `retries` |
| Redis 连接失败 | Redis 密码不匹配 | 确认 `.env` 中 `REDIS_PASSWORD` 与 `docker-compose.yml` 一致 |
