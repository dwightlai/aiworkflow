# 知识库系统生产环境部署指南

版本：V1.2
编制：基础架构组
日期：2026-06-15

## 环境要求

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 应用服务器 | 4核 16GB | 8核 32GB |
| 向量数据库 | 8核 32GB SSD 500GB | 16核 64GB NVMe 1TB |
| 消息队列 | 2核 4GB | 4核 8GB |
| 对象存储 | 兼容 S3 协议 | MinIO / 腾讯云 COS |

## 部署步骤

### 第一步：基础环境准备

1. 安装 Docker 24.0+ 和 Docker Compose v2.20+
2. 配置 Docker 数据目录到独立分区（至少 200GB）
3. 关闭防火墙或开放端口：80, 443, 8080, 9200, 5432, 19530
4. 设置系统参数：`vm.max_map_count=262144`

### 第二步：拉取镜像

```bash
docker pull registry.example.com/kb-api:v2.3.1
docker pull registry.example.com/kb-worker:v2.3.1
docker pull milvusdb/milvus:v2.4.0
docker pull minio/minio:RELEASE.2024-01
docker pull rabbitmq:3.12-management
```

### 第三步：配置与启动

```bash
cp .env.example .env
# 编辑 .env 中的数据库密码、JWT密钥、存储端点
docker compose up -d
```

### 第四步：初始化数据库

```bash
docker compose exec kb-api python manage.py migrate
docker compose exec kb-api python manage.py create_admin
```

### 第五步：创建默认分块策略

登录管理后台 → 知识库配置 → 分块策略 → 新建策略：
- 策略名称：default-policy
- 分块长度：2048 tokens
- 重叠长度：128 tokens
- 分隔符序列：`\n## ` → `\n### ` → `\n\n` → `\n` → ` `

### 第六步：配置模型服务

在系统配置中填入：
- Embedding 模型端点：`http://embedding-svc:8080/v1`
- LLM 模型端点：`http://llm-svc:8080/v1`
- 重排模型端点：`http://rerank-svc:8080/v1`

### 第七步：验证部署

```bash
# 健康检查
curl http://localhost:8080/api/health

# 创建测试知识库
curl -X POST http://localhost:8080/api/kb \
  -H "Content-Type: application/json" \
  -d '{"name":"test_kb","description":"部署验证"}'
```

## 故障排查

| 症状 | 可能原因 | 排查命令 |
|------|----------|----------|
| 向量写入失败 | Milvus 内存不足 | `docker logs milvus-standalone` |
| 文档解析超时 | Worker 数量不足 | `docker compose ps worker` |
| 用户无法登录 | JWT 密钥未配置 | `cat .env \| grep JWT` |
| 存储上传失败 | MinIO 凭证错误 | `curl http://localhost:9000/minio/health/live` |
