# RAG / 知识库分块问题测试样例包

本样例包针对视频「秋芝2046 · 企业知识库分块问题实战」中提到的典型分块缺陷设计，
覆盖上下文断裂、表格截断、QA配对打散、代码块截断等高频生产问题。

## 使用方法

1. 将 01~09 号样例文件逐个上传到知识库，或作为一个批次导入。
2. 导入后查看系统生成的切片，重点检查：
   - 步骤流程是否被切成多个块，前后逻辑是否可串联
   - 表格是否保留了表头和完整行
   - FAQ 问答对是否在同一 chunk 内
   - 代码块 / JSON 是否被截断
   - 标题层级是否随内容一起保留
   - 条款引用条件列表是否完整
   - 长段落答案是否跨 chunk 边界被切断
   - 会议纪要的多议题是否混在一起
3. 使用 `14_chunking_test_questions.csv` 里的问题进行检索测试。
4. 核心判断标准：一个可回答问题所需的最小证据，必须落在同一个 chunk 内，
   或能通过子 chunk 召回 + 父 chunk 回填完整取回。
