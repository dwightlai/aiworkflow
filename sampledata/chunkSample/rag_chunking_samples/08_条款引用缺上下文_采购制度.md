# 软件订阅服务采购管理制度

版本：V1.3
生效日期：2026-07-01
适用范围：华南分公司本部及下属项目部

## 一、总则

本制度用于规范办公软件订阅、SaaS 服务续费、API 调用额度采购等行为。
所有软件订阅采购必须在 OA 系统中发起，禁止线下口头审批后补单。

## 二、采购权限

软件订阅服务无论金额大小，均须满足以下全部条件方可采购：

1. 信息化部门出具《安全与数据合规评估报告》，确认服务不涉及
   将客户数据、档案数据或个人信息传输至境外服务器。

2. 若涉及客户数据、档案数据、个人信息或第三方 API 接口调用，
   法务部门须出具《合同条款合规复核意见》。

3. 单笔金额超过 50,000 元的，须取得至少三家供应商报价并形成
   《比价记录》。因唯一供应商原因无法比价的，须上传原厂独家
   授权证明或说明函。

4. 涉及源代码、模型权重、数据集交付的订阅服务，技术部门须
   出具《技术资产入库确认单》。

## 三、禁止采购情形

以下任一情况禁止采购：

1. 供应商注册地为境外且无中国境内实体或服务节点。
2. 服务条款中含有"数据可转移至境外"或"共享给关联第三方"的。
3. 供应商近 12 个月内有重大数据泄露记录。
4. 预期上线时间不足 30 天且未走"紧急采购"通道的。

## 四、附则

违反本制度擅自采购的，由当事人及审批人承担相应责任，并记入
供应商管理黑名单记录。
