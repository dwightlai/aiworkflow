# 智能体高级调试参数折叠设计

## 目标

简化管理端智能体多轮对话测试界面，将低频使用的“附加变量 JSON”从常驻表单改为默认收起的高级调试项，同时保留向工作流传递自定义输入变量的能力。

## 适用范围

本次只修改管理端智能体测试抽屉：

- `web/apps/admin/src/components/bot/BotRunChatDrawer.tsx`
- 必要的页面状态与测试

不修改后端 Bot API，不删除 `input` 请求字段，不影响独立的终端 Chat 应用。

## 交互设计

- 测试消息输入框保持常驻。
- 消息框下方显示“高级调试参数”折叠入口，默认收起。
- 展开后显示“工作流输入 JSON”文本框。
- 默认值为 `{}`。
- JSON 内容不是空对象时，折叠标题显示“已配置”状态。
- 同一会话发送消息后保留当前 JSON。
- 点击“新会话”或重新打开测试抽屉时重置为 `{}`。

## 数据行为

发送消息时继续将 JSON 解析为对象，并通过现有 `input` 字段提交。

合法示例：

```json
{
  "documentId": "doc-1001",
  "department": "档案部"
}
```

输入不是 JSON 对象时禁止发送，并显示现有错误信息：

- 数组、字符串或数字：附加变量必须是 JSON 对象。
- JSON 语法错误：附加变量不是合法 JSON。

系统自动生成的 `message`、`history`、`botId`、`botName` 等变量仍由后端覆盖，避免调试参数替换系统上下文。

## 组件边界

`BotRunChatDrawer` 负责：

- 折叠状态展示。
- 根据表单中的 JSON 判断是否显示“已配置”。
- 展开和收起高级区域。

`BotsPage` 继续负责：

- JSON 解析和校验。
- 调用 `chatBot`。
- 新会话及打开抽屉时重置参数。

不引入新的全局状态或新的 API。

## 测试标准

- 初始渲染时看不到 JSON 文本框。
- 点击“高级调试参数”后显示 JSON 文本框。
- `{}` 不显示“已配置”。
- 非空对象显示“已配置”。
- 发送时自定义变量仍进入 `chatBot` 请求。
- 非法 JSON 阻止请求并显示错误。
- 新会话将 JSON 重置为 `{}`。
