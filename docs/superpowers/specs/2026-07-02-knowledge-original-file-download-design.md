# 知识库原始附件下载设计

## 目标

在知识库文档列表的文档名称旁提供原始附件下载入口。下载必须经过现有认证和知识库访问权限校验，且不得向前端暴露服务器磁盘路径。

## 设计

- 新增 `GET /api/knowledge-bases/{knowledgeBaseId}/documents/{documentId}/original`。
- 服务层校验文档属于目标知识库，并复用知识库使用权限校验。
- 仅允许下载配置的知识库原件目录内、且与文档 `storagePath` 一致的普通文件。
- 返回 `Content-Disposition: attachment`，文件名使用文档原名称并按 RFC 5987 编码。
- 文档列表响应增加 `originalFileAvailable`，不返回 `storagePath`。
- 管理端名称旁显示下载图标；没有原件时不显示。
- 下载请求使用现有 Bearer Token，通过 Blob 创建临时对象 URL，不采用无法携带认证头的裸链接。

## 验收

1. 上传且保存了原件的文档显示下载图标。
2. 手工录入或原件丢失的文档不显示图标。
3. 下载内容与上传原件一致，文件名正确。
4. 无权限、文档不属于知识库、文件不存在时返回明确错误。
5. API 不暴露本地存储路径。
