# 档案编研 DOCX 母版占位符与 content_json 映射说明

## 通用占位符

| DOCX 占位符 | content_json 字段 | 说明 |
|---|---|---|
| {{title}} | title | 成果标题 |
| {{subtitle}} | subtitle | 副标题 |
| {{cover.organization}} | cover.organization | 编研单位 |
| {{cover.publishDate}} | cover.publishDate | 编研时间 |
| {{cover.securityLevel}} | cover.securityLevel | 密级 |
| {{editorNote}} | editorNote | 编研说明 |
| {{summary}} | summary | 摘要/概述 |
| {{toc}} | sections[].title | 目录，可由渲染引擎生成 Word TOC 域 |

## 循环语法建议

- {{#sections}} ... {{/sections}}：章节循环
- {{#items}} ... {{/items}}：列表循环
- {{#events}} ... {{/events}}：事件循环
- {{#references}} ... {{/references}}：引用来源循环

## 样式约定

母版内已预置 RW_* 命名样式，包括：

- RW_CoverTitle：封面主标题
- RW_CoverSubtitle：封面副标题
- RW_CoverMeta：封面元信息
- RW_TocTitle：目录标题
- RW_TocEntry：目录条目
- RW_Heading1：一级标题
- RW_Heading2：二级标题
- RW_Heading3：三级标题
- RW_Body：正文
- RW_Quote：引用/占位说明
- RW_Caption：图表题注
- RW_Footnote：脚注
- RW_AppendixTitle：附录标题

## 开发建议

1. DOCX 母版只负责版式、样式和占位符。
2. content_json 负责内容结构、章节、表格、图片、时间轴和引用。
3. 渲染引擎读取 templateType，选择对应 renderer。
4. 引用建议优先渲染为脚注，同时在文末生成参考文献表。
5. 图片类字段建议统一用 imageRef，由文件服务解析真实路径。
