## 第01章 序言

### 概要说明

AI Workflow 是面向企业 AI 应用搭建的管理平台，提供模型配置、Prompt 管理、知识库管理、工作流编排、智能体封装、运行监控和组织权限管理能力。

系统核心使用路径：

1. 在模型配置中接入大模型或嵌入模型。
2. 在知识库中创建知识库并导入资料。
3. 在 Prompt 中维护可复用提示词模板。
4. 在工作流中编排开始、知识库、大模型、问题分类、HTTP 请求、结束等节点。
5. 发布工作流后，在智能体 Bots 中绑定工作流并进行对话测试。
6. 在运行监控中查看执行结果、节点输入输出和错误信息。

### 登录与工作台

进入系统后，使用账号登录后台。登录成功后默认进入工作台。

工作台展示以下信息：

- 总工作流数量
- 今日执行次数
- 运行成功率
- 平均耗时
- 最近工作流
- 运行态势
- 快捷入口

常用入口：

- 新建工作流：进入工作流设计器。
- 查看运行监控：查看工作流运行历史。
- 最近工作流：快速进入已有流程编辑和调试。

## 第02章 AI 功能

## 1. 智能体 Bots

### 模块概述

智能体 Bots 用于把模型、知识库或已发布工作流包装成可运行的对话式应用。适合客服问答、知识助手、流程助手、业务咨询等场景。

智能体支持：

- 新增、编辑、删除智能体
- 绑定已发布工作流
- 直连模型和知识库
- 配置系统提示词
- 配置开场白
- 启用或停用智能体
- 运行测试并保留会话记录

### 操作使用

1. 进入 AI 功能 > 智能体 Bots。
2. 点击新增智能体。
3. 填写智能体名称、描述、头像、开场白。
4. 选择应用方式：
   - 绑定工作流：选择一个已发布工作流。
   - 直连智能体：选择模型配置，可选绑定知识库。
5. 填写系统提示词。
6. 设置状态为启用。
7. 保存后点击运行。
8. 在对话窗口输入消息，并填写运行参数 JSON。
9. 查看模型回复和本次执行详情。

### 常见问题

**为什么工作流下拉框为空？**

需要先创建并发布工作流，未发布的工作流不会作为正式智能体流程使用。

**为什么运行失败？**

检查智能体绑定的模型、知识库、工作流是否有效；如果绑定工作流，进入运行监控查看失败节点。

**直连智能体和工作流智能体有什么区别？**

直连智能体适合简单对话；工作流智能体适合需要知识检索、分类分流、HTTP 调用等复杂流程的场景。

## 2. 工作流

### 模块概述

工作流用于通过可视化节点编排 AI 自动化流程。系统支持从空白 DAG 开始搭建流程，并支持保存草稿、发布、运行调试、归档和查看运行记录。

当前支持的核心节点：

- 开始：接收调试、API 或智能体输入。
- 知识库：根据输入变量检索知识片段。
- 大模型：调用模型生成文本、JSON 或代码。
- 问题分类：按分类规则把问题路由到不同分支。
- HTTP 请求：调用外部 API。
- 结束：整理最终输出。
- Prompt 模板：渲染提示词。
- 内容模板：生成文本或 JSON 内容。
- 条件分支：按上下文变量选择后续节点。
- 循环：遍历数组并执行循环体步骤。

### 操作使用-工作流创建

1. 进入 AI 功能 > 工作流。
2. 点击创建工作流或空白工作流。
3. 进入工作流设计器。
4. 设置工作流名称和描述。
5. 从左侧节点库拖拽节点到画布。
6. 使用节点端口连线。
7. 点击节点打开属性面板，填写节点配置。
8. 点击保存草稿。

### 操作使用-流程编排

基础问答流程：

1. 开始节点接收 `question`。
2. 知识库节点选择知识库，查询文本填写 `${input}` 或 `{{question}}`。
3. 大模型节点选择模型，用户消息中引用知识库输出。
4. 结束节点选择输出变量 `content`。
5. 连线顺序：开始 > 知识库 > 大模型 > 结束。

问题分类流程：

1. 开始节点接收用户问题。
2. 问题分类节点配置输入变量、输出变量和分类项。
3. 为每个分类项填写分类 ID、分类名称、关键词、匹配方式和命中后跳转节点 ID。
4. 将分类节点连接到多个后续节点。
5. 可在连线条件中填写 `questionCategory == consult` 或 `questionCategory == after_sales`。
6. 未命中时可配置默认跳转节点。

HTTP 请求流程：

1. 添加 HTTP 请求节点。
2. 配置请求方法、请求地址、Params、Headers。
3. 配置 Body 类型：
   - JSON
   - Raw
   - Form Data
   - None
4. 在 Body 内容中使用上下文变量，例如 `{"question":"{{question}}"}`。
5. 选择响应 Body 类型为文本或 JSON。
6. 设置输出变量，例如 `httpResult`。
7. 后续节点可引用 `httpResult.statusCode`、`httpResult.body` 等字段。

### 操作使用-调试发布

1. 在设计器右上角点击调试。
2. 输入调试 JSON，例如：

```json
{
  "question": "请介绍退款政策"
}
```

3. 点击运行。
4. 查看整体运行状态和各节点输入输出。
5. 确认流程无误后点击保存草稿。
6. 点击发布。
7. 发布后可被智能体或开放接口调用。

### 常见问题

**为什么发布失败？**

工作流必须有且只有一个开始节点，至少一个结束节点，连线不能引用不存在的节点，流程不能成环。

**为什么大模型节点没有可选模型？**

需要先在模型配置中新增并启用用途为对话的模型。

**为什么知识库节点没有可选知识库？**

需要先创建知识库，并确保知识库已导入资料。

**为什么结束节点没有输出？**

检查结束节点的输出变量是否和上游节点输出一致，例如大模型默认输出 `content`。

## 3. 运行监控

### 模块概述

运行监控用于查看所有工作流执行记录，包括运行状态、输入、输出、错误信息和节点级执行明细。

运行状态包括：

- RUNNING：运行中
- SUCCEEDED：运行成功
- FAILED：运行失败

节点状态包括：

- RUNNING
- SUCCEEDED
- FAILED
- SKIPPED

### 操作使用

1. 进入 AI 功能 > 运行监控。
2. 查看运行列表。
3. 点击某条记录进入执行详情。
4. 查看工作流输入、最终输出和错误信息。
5. 查看每个节点的输入、输出、状态、开始时间和结束时间。
6. 如果运行失败，定位失败节点并返回工作流设计器修改配置。

### 常见问题

**如何排查 HTTP 请求失败？**

查看 HTTP 节点的输入参数、请求地址、Header、Body 和错误信息。

**如何排查大模型调用失败？**

检查模型配置是否启用，API Key 是否正确，模型 Base URL 和模型名称是否匹配。

**如何排查流程没有进入预期分支？**

查看问题分类或条件分支节点输出，并确认连线条件是否和输出变量一致。

## 4. Prompt

### 模块概述

Prompt 模块用于集中管理提示词模板。模板可被工作流中的 Prompt 节点引用，避免在多个流程中重复维护提示词。

支持能力：

- 新增 Prompt 模板
- 编辑 Prompt 模板
- 删除 Prompt 模板
- 自动识别模板变量
- 在工作流节点中引用模板

### 操作使用

1. 进入 AI 功能 > Prompt。
2. 点击新增 Prompt。
3. 填写模板名称和描述。
4. 编写模板内容，例如：

```text
请根据以下用户问题生成专业回复：
{{question}}
```

5. 保存模板。
6. 在工作流设计器中添加 Prompt 模板节点。
7. 在节点属性中选择已保存 Prompt。
8. 设置输出变量。

### 常见问题

**变量怎么写？**

使用 `{{变量名}}` 或 `${变量名}` 形式引用上下文变量。

**模板变量没有值怎么办？**

检查上游节点是否输出了对应变量，或开始节点输入 JSON 是否包含该字段。

## 5. 知识库

### 模块概述

知识库用于管理企业资料，并支持在工作流中进行检索增强生成。适合制度问答、产品说明、业务知识、FAQ、表格资料等场景。

支持能力：

- 创建知识库
- 配置向量库
- 选择嵌入模型
- 上传文本文档
- 上传表格文档
- 手动录入数据集
- 预览分段结果
- 编辑知识切片
- 搜索知识库
- 在工作流中通过知识库节点调用

### 操作使用-知识库创建

1. 进入 AI 功能 > 知识库。
2. 点击新建知识库。
3. 填写知识库名称和描述。
4. 选择嵌入模型。
5. 选择向量库配置。
6. 设置向量维度。
7. 设置分段策略：
   - 普通文本
   - Markdown 标题
   - 正则分隔
8. 设置检索模式：
   - 关键词
   - 向量
   - 混合检索
9. 保存知识库。

### 操作使用-资料上传

资料上传方式：

- 手动数据集：逐条填写标题、内容、标签、分类、来源。
- 文本文档：上传文本类文件并配置分段。
- 表格文档：上传表格资料并配置处理参数。

上传步骤：

1. 进入某个知识库。
2. 点击新增文档。
3. 选择上传方式。
4. 配置分段参数。
5. 预览分段结果。
6. 确认上传。
7. 上传完成后在文档列表查看处理状态。

### 操作使用-检索验证

1. 进入知识库详情。
2. 使用搜索功能输入测试问题。
3. 设置 Top-K。
4. 查看返回片段和相似度。
5. 如果结果不理想，调整分段策略、chunk 大小、重叠长度或检索模式。

### 操作使用-流程调用

1. 在工作流设计器添加知识库节点。
2. 选择目标知识库。
3. 配置查询文本。
4. 设置检索数量 Top-K。
5. 设置相似度阈值。
6. 使用输出变量：
   - `content`：拼接后的知识内容
   - `sources`：原始检索结果
   - `query`：实际查询文本
7. 在大模型节点中引用 `content` 作为上下文。

### 常见问题

**知识库搜索不到内容？**

检查文档是否上传成功、切片是否启用、检索模式是否合适、查询词是否和资料内容相关。

**知识库节点输出为空？**

检查查询文本是否为空，知识库 ID 是否正确，相似度阈值是否过高。

**表格文档怎么处理？**

使用表格文档上传入口，先预览处理结果，再确认上传。

## 6. 模型配置

### 模块概述

模型配置用于接入第三方或自定义大模型服务。工作流的大模型节点、知识库嵌入处理和智能体运行都依赖模型配置。

支持模型类型：

- DeepSeek
- OpenAI
- Anthropic
- Zhipu
- Moonshot
- Qwen
- MiniMax
- VolcEngine
- SiliconFlow
- Ollama
- Custom

支持用途：

- 对话
- 嵌入
- 重排
- 多模态

### 操作使用

1. 进入 AI 功能 > 模型配置。
2. 点击新增模型。
3. 选择模型类型。
4. 选择模型用途。
5. 填写模型名称、Base URL、模型标识。
6. 填写 API Key。
7. 配置是否支持视觉。
8. 可选填写百万 Token 价格。
9. 设置启用状态。
10. 保存配置。

### 常见问题

**工作流大模型节点应该选择什么用途？**

选择用途为对话的模型。

**知识库嵌入模型应该选择什么用途？**

选择用途为嵌入的模型。

**模型配置保存后无法调用怎么办？**

检查 Base URL、模型名称、API Key、启用状态和网络连通性。

## 第03章 系统管理

## 1. 组织用户

### 模块概述

组织用户模块用于管理组织架构、用户、角色和第三方应用接入。适合多组织、多角色、多系统集成的后台管理场景。

支持内容：

- 组织架构
- 用户
- 角色
- 第三方应用
- 授权范围

### 操作使用-组织管理

1. 进入系统管理 > 组织用户。
2. 切换到组织架构。
3. 新增组织。
4. 填写组织名称、编码、组织类型、外部标识。
5. 设置状态。
6. 保存后可编辑、启用、停用或删除。

### 操作使用-用户管理

1. 切换到用户。
2. 新增用户。
3. 填写姓名、登录名、密码、用户类型。
4. 选择所属组织和角色。
5. 设置排序。
6. 保存用户。
7. 后续可启用、禁用、锁定、重置密码或删除用户。

### 操作使用-角色管理

1. 切换到角色。
2. 新增角色。
3. 填写角色名称、编码、角色类型。
4. 保存角色。
5. 将角色分配给用户。

### 操作使用-第三方应用

1. 切换到第三方应用。
2. 新增应用。
3. 选择应用类型。
4. 配置认证方式。
5. 设置授权范围和权限：
   - 租户
   - 组织
   - 智能体
   - 知识库
   - 模板
6. 保存应用后用于外部系统调用。

### 常见问题

**用户无法登录怎么办？**

检查用户状态是否为启用，密码是否正确，账号是否被锁定。

**第三方应用调用失败怎么办？**

检查应用状态、认证方式、授权范围和权限配置。

## 第04章 典型流程

### 搭建知识库问答智能体

1. 在模型配置中新增对话模型。
2. 在模型配置中新增嵌入模型。
3. 在知识库中创建知识库。
4. 上传文档并确认切片。
5. 在工作流中新建流程。
6. 编排节点：开始 > 知识库 > 大模型 > 结束。
7. 在知识库节点选择知识库。
8. 在大模型节点引用知识库输出 `content`。
9. 调试通过后发布工作流。
10. 在智能体 Bots 中新增智能体并绑定该工作流。
11. 运行智能体测试问答效果。

### 搭建 HTTP 工具调用流程

1. 新建工作流。
2. 编排节点：开始 > HTTP 请求 > 大模型 > 结束。
3. 在 HTTP 请求节点配置接口地址、请求方法、Header 和 Body。
4. 在 Body 中引用用户输入，例如 `{{question}}`。
5. 设置响应 Body 类型。
6. 在大模型节点引用 HTTP 输出。
7. 调试成功后发布。

### 搭建问题分类分流流程

1. 新建工作流。
2. 编排节点：开始 > 问题分类。
3. 添加多个业务处理分支，例如售前咨询、售后退款、其他问题。
4. 在问题分类节点配置分类项和关键词。
5. 为不同分支配置命中后跳转节点，或使用连线条件。
6. 每个分支最终连接到结束节点。
7. 使用不同问题进行调试，确认分流正确。
